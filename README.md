# CodeAlpha_RandomQuoteGenerator

A random quote generator built for the CodeAlpha App Development Internship (Task 2).

## Features

- Displays a random quote (text + author) on load and on button click
- "New Quote" button that avoids repeating the immediately previous quote
- Category filter (Motivational, Tech, Funny, Wisdom, Cybersecurity)
- Copy-to-clipboard button
- Share-on-X/Twitter button (pre-fills the quote as a tweet)
- Auto-rotate mode: new quote every 8 seconds, toggleable
- Dark mode toggle (persists via localStorage)
- Keyboard shortcut: press Space for a new quote
- Smooth fade transition between quotes
- Clean, responsive, minimal UI

## How to run

1. Clone this repo
2. Open `index.html` in your browser (or use the VS Code "Live Server" extension)

No build steps or dependencies required: pure HTML, CSS, and JavaScript. Quotes are stored locally in `script.js`, so the app works fully offline.

## Tech stack

HTML5, CSS3, vanilla JavaScript, browser localStorage, Clipboard API.
